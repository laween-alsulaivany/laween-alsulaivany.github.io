# Laween Al-Sulaivany

Personal portfolio website built with Astro and TypeScript.

**Live site:** https://laween-alsulaivany.github.io/

The site includes my education and experience, projects, and background.

## Built with

- Astro
- TypeScript
- [LA UI](https://github.com/laween-alsulaivany/LA_UI)
- GitHub Pages

LA UI is a personal CSS style guide that is included as a Git submodule and provides the shared design system used by the site.
